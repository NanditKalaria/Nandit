# Personal Portfolio Website

A modern, responsive portfolio website built with React, TypeScript, and Tailwind CSS.

## 🚀 Live Demo
[Visit Website](https://nanditkalaria.me)

## 🛠️ Technologies Used

- React
- TypeScript
- Tailwind CSS
- Framer Motion
- Vite

## ⚙️ Setup and Installation

1. Clone the repository
```bash
git clone https://github.com/yourusername/portfolio.git
```

2. Install dependencies
```bash
cd portfolio
npm install
```

3. Run development server
```bash
npm run dev
```

4. Build for production
```bash
npm run build
```

## 🌐 Deployment

This website is deployed on Vercel with a custom domain setup. To deploy your own version:

1. Push your code to GitHub
2. Connect your repository to Vercel
3. Configure custom domain settings in Vercel dashboard
4. Add required DNS records at your domain registrar
